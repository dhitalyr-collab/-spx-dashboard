SPX MACRO & 0DTE DASHBOARD — V4

WHY V4
------
TradingView blocks several exchange/index symbols in third-party embeds.
V4 therefore:
- Uses TradingView ONLY for SPY and QQQ, which were confirmed to work.
- Uses Investing.com's official embeddable technical-summary tool for
  selected macro/index/commodity references.
- Uses Investing.com's official economic-calendar embed.
- Provides one-tap direct live/reference source pages for SPX, VIX, 10Y,
  2Y, WTI, Brent and DXY.
- Clearly labels ES, NQ and ZN as delayed on free public data because
  exchange licensing prevents unrestricted true real-time redistribution.

IMPORTANT
---------
For an actual 0DTE entry, use your broker's executable quote. Free public
futures pages can be delayed and derived/reference prices are not guaranteed
to equal an executable market price.

HOW TO REPLACE V3/V3.1 ON GITHUB
---------------------------------
1. Unzip this V4 package on your iPhone.
2. Open your existing GitHub spx-dashboard repository in Safari.
3. Replace index.html with this V4 index.html.
4. Also replace manifest.webmanifest and sw.js.
5. The icon files can stay, or upload the included ones.
6. Commit changes to main.
7. Wait 1–3 minutes.
8. Open your GitHub Pages dashboard.
9. If the old version still appears, fully close the Home Screen web app,
   reopen it, and refresh. If necessary remove the Home Screen icon once
   and add it again after GitHub Pages shows V4.
